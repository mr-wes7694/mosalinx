# Mosalinx

A cloud-based collaborative workspace designed to bring creative teams together in one unified platform.

Mosalinx combines project management, team communication, resource organization, activity tracking, and AI-assisted brainstorming into a single collaborative workspace. Instead of switching between multiple applications, creators can manage their projects, ideas, files, and collaboration from one central location.

---

## Project Vision

Creative teams often rely on multiple disconnected tools to organize their work. Mosalinx aims to simplify that workflow by providing an integrated platform where users can:

- Create and manage projects
- Collaborate with team members
- Organize project resources
- Track project activity and progress
- Communicate within dedicated project workspaces
- Generate and save ideas using AI-assisted brainstorming

## Git Workflow

The project follows a collaborative Git workflow to support parallel development.

### Branches

- **main** – Stable, production-ready code
- **development** – Primary integration branch for ongoing development
- **feature/*** – Individual feature branches created from `development`

Feature branches are merged into the `development` branch through pull requests after testing and review.
